# Legacy ASL reference source

Original project: https://github.com/elle-Bee/ASL-interpreter

Reference revision: `b6c0442a6476093194f6adda0c11c0009935f175`.

This directory is archived reference code, not the running Tandem recognition service. On 2026-10-05 its broken parent gitlink was replaced with source files so the owner's existing local README, requirements, inference and overlay changes are preserved in the Tandem repository. The original nested Git metadata is retained locally in the ignored `.git-upstream-reference/` directory; no push was made to the upstream author's repository. Use `git --git-dir=ASL-interpreter/.git-upstream-reference --work-tree=ASL-interpreter` from the project root to inspect the original checkout history.

Generated model/data pickles, Python virtual environments and caches are excluded. The previously deleted model is not restored. Runtime models must be generated or obtained separately; this snapshot does not establish model accuracy or current dependency compatibility.
